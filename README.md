# ⏰ Real-Time Digital Clock in C++

A terminal-based Real-Time Digital Clock developed in C++ featuring a dynamic ASCII dashboard, live system-time synchronization, and flexible time formatting (12-hour/24-hour toggling). 

Developed as part of **Task 2** during the C++ Programming Internship at **SAM AI Technologies**.

---

## ✨ Features

* **Live System Time Sync:** Fetches and updates system time accurately in real-time.
* **ASCII Dashboard UI:** Styled console layout for enhanced readability.
* **12/24-Hour Format Support:** Flexible display settings tailored for user preferences.
* **Cross-Platform Readiness:** Built using core standard C++ libraries (`<ctime>`, `<chrono>`, `<thread>`).

---

## 🛠️ Tech Stack & Concepts Used

* **Language:** C++
* **Libraries:** `<iostream>`, `<ctime>`, `<chrono>`, `<thread>`
* **Concepts:** Time manipulation, loop synchronization, terminal manipulation, procedural structuring.
