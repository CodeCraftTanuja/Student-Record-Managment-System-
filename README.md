# Student Record Management System

A console-based C++ application developed for managing student records using Object-Oriented Programming (OOP) concepts and dynamic memory management.

## Features
- **Add Records:** Input student details including roll number, name, and marks.
- **Display All Records:** Formatted view of all enrolled students using `<iomanip>`.
- **Search Record:** Find a student quickly using their unique roll number.
- **Update Record:** Modify existing student information.
- **Delete Record:** Remove student records dynamically from memory.

## Technical Details
- **Language:** C++
- **Core Concepts:** OOP (Classes & Encapsulation), STL (`std::vector`), Stream Formatting (`<iomanip>`)
